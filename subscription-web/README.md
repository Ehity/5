# Сбер.Сканер Подписок — веб-сервис (MVP)

Тёмный финтех-дашборд: загружаете CSV-выписку — сервис находит регулярные
списания, считает потенциальную экономию и генерирует готовое заявление
на отмену автопродления.

## Стек

- **Backend**: FastAPI + Uvicorn (анализ выписки, поиск подписок, генерация писем)
- **Frontend**: React 18 + Vite + Tailwind CSS + Recharts (дашборд, графики)

## Запуск одной кнопкой

Двойной клик по **`start_web.bat`** (или ярлык **«Сканер Подписок Web»** на
рабочем столе): поднимет сервер и откроет страницу **http://127.0.0.1:8000**.

Frontend раздаётся из production-сборки (`frontend/dist`) прямо FastAPI —
Node-сервер для работы не нужен. Для пересборки UI: `cd frontend && npm run build`.

## Режим разработки

```bash
cd backend  && python -m uvicorn main:app --port 8000   # API на :8000
cd frontend && npm run dev                              # UI на :5173 (прокси /api)
```

## API

| Метод | Эндпоинт              | Описание                                        |
|-------|-----------------------|-------------------------------------------------|
| GET   | `/api/health`         | Статус сервиса                                  |
| GET   | `/api/subscriptions`  | Найденные подписки (или demo-mock, если выписки нет) |
| POST  | `/api/upload`         | multipart-загрузка CSV-выписки → анализ         |
| POST  | `/api/generate-letter`| `{name, amount}` → текст заявления на отмену    |
| POST  | `/api/reset`          | Вернуться в демо-режим                          |

## Как работает анализ

1. **Парсинг CSV** (utf-8/cp1251, разделители `;`/`,`/tab, алиасы колонок).
2. **Нормализация названий**: `YNDX_PLUS`, `YNDX.MUSIC`, `ЯНДЕКС.ПЛЮС` →
   одна подписка «Яндекс Плюс» (словарь брендов + fallback-группировка по токенам).
3. **Детект периодичности**: ≥2 списания, медиана интервалов ~20–40 дней
   (месяц) или ~340–390 (год), суммы в пределах ±15% от медианы.
4. **Fallback**: если выписка не загружена/пуста — красивые демо-данные,
   чтобы интерфейс всегда был готов к презентации.

## Ручной запуск

```bash
# backend
cd backend && python -m uvicorn main:app --port 8000
# frontend
cd frontend && npm install && npm run dev
```
